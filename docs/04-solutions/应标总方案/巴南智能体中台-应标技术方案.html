技术应标文件

医疗 AI 智能体统一中台建设方案

对应招标文件「二、智能体中台建设」（一）～（五）全部条款的技术响应
项目名称：重庆市巴南区人民医院宫颈癌诊疗综合场景 AI 智能体及数据驾驶舱一体化建设项目
响应章节：第二章 智能体中台建设
对应采购分项：AI 智能体中台平台软件（第 1 项）
编制日期：2026 年 9 月

一、技术架构总览

本方案以「分层解耦、能力复用、利旧优先」为设计原则，将智能体中台划分为七个技术层级。自下而上，下层为上层提供能力支撑；每一层均可独立演进，新增 AI 能力无需改动已有层级。

整体适配医院现有虚拟化与容器底座，中台全部组件及上层智能体应用均采用容器化部署，充分利用现有服务器硬件资源，不新增 GPU 服务器采购。

二、L1 容器化基础设施底座

对应条款（一）：统一技术底座——采用容器化部署架构，提供统一算力调度、任务编排、资源隔离、日志监控、权限管控能力。

本层可实现的功能

功能能力具体实现说明
容器化统一部署中台全部组件与上层智能体应用均以容器镜像形态封装交付，支持一键部署、一键升级、一键回滚，部署过程不依赖互联网。
集群高可用多节点集群部署，关键组件多副本运行；节点故障时业务自动迁移至健康节点，服务不中断。
统一任务编排提供统一的容器编排调度能力，支持应用编排、依赖管理、启动顺序控制、健康检查与自动重启。
网络策略管控应用间东西向流量按需放通、默认拒绝，对外访问统一出口，满足院内网络安全要求。
权限管控基于角色的分级权限体系，对接院内统一身份认证，所有管理操作留痕可查。
日志集中管理容器运行日志、应用业务日志集中采集、统一存储、支持全文检索。
离线交付能力适配院内网无外网环境，全部镜像、依赖包、模型文件在交付前完成离线打包与本地化部署。

技术实现路径

采用业界成熟的容器编排技术构建中台底座，所有服务以容器镜像形式交付并纳入院内私有镜像仓库统一管理，确保内网环境可完整复现部署。集群采用多节点冗余部署，通过健康探针与副本机制实现故障自愈。资源隔离依托命名空间与配额机制实现，网络隔离依托网络策略实现。全部组件均支持离线安装，不产生任何对外网络依赖。

三、L2 算力资源池与调度

对应条款（一）：实现算力资源动态分配，支持 GPU/CPU 资源池化管理，对各智能体任务进行优先级调度、任务熔断、异常告警。

本层可实现的功能

功能能力具体实现说明
算力资源池化将现有服务器的 GPU、CPU 资源统一纳管为资源池，屏蔽物理机差异，按任务需求统一分配，不以物理机为单位绑定资源。
动态分配依据任务负载自动分配与回收算力，空闲资源自动释放回池，峰值需求按策略排队或弹性调度。
显存共享与切分支持单张 GPU 卡被多个推理任务共享使用，按需切分显存额度，显著提升医院现有硬件利用率。
优先级调度支持按业务场景设置任务优先级：临床实时类任务（病历生成、报告解读、影像辅助）优先调度；批量类任务（数据集标注、模型评测、数据治理）低优先级排队执行。
任务熔断单任务超时、连续失败或资源占用超限时自动熔断终止，防止异常任务拖垮整体服务。
异常告警对 GPU 温度、显存占用、任务失败率、队列积压、节点离线等指标设置阈值，触发告警并通知运维人员。
利旧适配整体适配医院现有服务器虚拟化环境，充分利用现有硬件资源。

技术实现路径

以容器编排平台为底座，通过设备插件机制将 GPU 资源纳入统一调度体系；通过队列与优先级机制实现任务分级调度；通过显存切分技术实现单卡多任务共享，解决医院现有 GPU 资源有限的问题。算力监控数据统一采集至监控体系，与 L7 运维监控联动。

四、L3 多模型统一接入管理

对应条款（二）：支持大语言模型、影像 AI 模型、病理 AI 模型等多类型模型接入纳管；支持本地部署模型、API 服务模型统一注册、版本管理、模型启停、性能监控；提供模型接入标准化规范，可按需新增、替换、升级模型，做到业务应用与底层模型解耦。

本层可实现的功能

功能能力具体实现说明
多类型模型纳管统一纳管大语言模型、影像 AI 模型、病理 AI 模型等不同类型模型，屏蔽底层框架与调用协议差异；影像、病理类模型按其原厂商接口接入，中台负责注册、版本、启停与调用监控，不改变其原有推理实现。
双形态接入同时支持院内本地部署模型与外部 API 服务模型的注册接入，两类模型在中台内统一管理、统一调用。
统一注册与台账模型统一注册登记，形成模型清单台账，记录模型名称、类型、版本、来源、责任科室、上线时间、适用范围。
版本管理支持模型多版本并存、版本切换、一键回退；版本变更全程留痕，可追溯每次变更的操作人、时间与原因。
模型启停支持按需启动、停止模型服务，停用模型自动释放其占用的算力资源。
性能监控监控模型响应时延、调用成功率、吞吐量、资源占用与错误分布，异常自动告警。
标准化接入规范制定并交付《模型接入标准化规范》，明确接口协议、数据格式、鉴权方式、健康检查、错误码定义；后续新增模型按规范接入，无需定制开发。
业务与模型解耦上层智能体应用通过统一模型服务接口调用，模型替换、升级、切换版本均无需修改应用代码。

五、L4 智能体开发与快速迭代

对应条款（二）：提供低代码/配置化智能体开发工具，支持提示词编排、工作流编排、业务规则配置；支持基于中台快速开发、调试、发布新的专科 AI 应用；支持应用灰度发布、版本回滚，满足业务持续迭代更新需求。

本层可实现的功能

功能能力具体实现说明
提示词编排提示词模板化管理，支持变量注入、多场景复用、版本管理与变更留痕。
工作流编排支持顺序执行、条件分支、并行处理、循环迭代、人工审核等流程节点，支持多智能体协同编排。
在线调试提供独立调试环境，支持单步执行、中间结果查看、调用日志追踪，调试过程不影响生产环境。
一键发布编排完成后一键发布为可调用服务，自动生成调用接口与说明文档。
灰度发布支持按科室、用户、流量比例灰度放量，灰度期间可随时中止并回退，不影响存量业务。
版本回滚保留历史版本完整快照，异常时一键回滚至上一稳定版本，回滚过程秒级完成。

六、L5 服务网关与能力封装

对应条款（三）：提供统一 AI 服务网关，将模型能力封装为标准化 API 服务，供上层智能体应用调用；具备接口鉴权、限流、熔断、流量统计、调用链路日志留存。

本层可实现的功能

功能能力具体实现说明
统一服务网关所有模型能力、智能体能力统一封装为标准 API 服务，对外提供统一调用入口，形成统一服务目录。
能力封装将底层模型推理能力封装为标准服务接口，屏蔽不同模型的技术差异，上层应用按统一格式调用。
接口鉴权采用令牌鉴权与角色权限双重校验，未授权调用直接拦截并记录。
限流支持按应用、接口、时段配置限流策略，防止异常流量冲击后端模型服务。
熔断降级下游服务异常时自动熔断，返回降级响应，避免单点故障扩散至整个中台。
流量统计统计各接口调用量、成功率、平均时延、错误分布，按应用与时间维度出报表。
调用链路日志完整记录调用链路日志，包含调用方、时间、参数摘要、结果状态、耗时，支持检索与追溯。
统一纳管医院各业务系统对接服务统一纳入网关管理，接口调用统一鉴权、统一监控。

技术实现路径

网关作为中台唯一服务出口，位于上层应用与下层模型之间。所有调用需先经网关完成身份校验、权限判定、流量控制，再转发至后端服务；调用全过程生成链路日志并汇总至监控体系。网关自身支持多副本部署，避免成为单点。

七、L6 数据服务能力

对应条款（四）：中台提供统一数据访问接口，对接专题数据集，为各 AI 智能体提供合规的数据读取能力，落实数据访问权限控制，禁止越权访问患者隐私数据。

本层可实现的功能

功能能力具体实现说明
统一数据访问接口提供统一数据服务接口，各智能体通过标准接口读取数据，非特殊情况不直连业务系统数据库。
专题数据集对接对接宫颈癌诊疗高质量专题数据集，提供数据集访问服务，支撑模型迭代与科研分析。
数据权限控制按角色、科室、业务场景分级授权，遵循最小必要原则，只开放业务必需的数据范围。
越权访问阻断支持字段级、行级权限校验，越权请求直接拒绝并记录，从机制上禁止越权访问患者隐私数据。
隐私数据保护患者隐私字段脱敏后对外提供，落实去标识化处理，满足医疗数据分级分类管理要求。
数据访问审计完整记录数据访问主体、时间、范围、用途与结果，全流程可追溯审计。
业务系统对接支持与医院数据集成平台、数据仓库、HIS、LIS、PACS、超声系统、体检系统的对接。
多形式接口支持 API 接口、消息队列、数据视图等多种对接方式，优先复用医院现有数据集成平台。

八、L7 运维监控与审计

对应条款（五）：对模型运行状态、调用次数、响应时延、报错情况、资源占用进行集中监控，支持指标告警；提供完整审计日志，记录模型调用、智能体操作行为。

本层可实现的功能

功能能力具体实现说明
可视化集中监控大盘提供监控大屏与 PC 端视图，支持按模型、智能体、科室、时间维度查看运行状态、调用次数、响应时延、报错情况与资源占用。
指标告警支持自定义告警阈值与告警规则，触发后通过院内合规渠道通知运维人员，支持告警分级。
审计日志完整记录模型调用、智能体操作行为，包含操作主体、时间、对象、结果，无遗漏、不可篡改。
日志留存日志集中存储，留存期限满足网络安全等级保护与电子病历分级评价相关要求。
日志防篡改审计日志独立存储并采取防篡改保护，仅授权人员可查询，不可修改删除。
数据驾驶舱联动监控指标通过中台接口对外输出，供数据驾驶舱「AI 应用运行监控主题」调用。

九、合规、交付与服务保障

对应条款（十二）：项目通用技术及商务要求。

9.1 部署要求响应

中台及上层智能体应用全部采用容器化部署，整体适配医院现有虚拟化与容器底座，充分利旧现有硬件资源；本项目不含 GPU 服务器硬件采购，全部算力调度基于医院现有服务器资源实现。

9.2 合规要求响应

方案满足网络安全、数据安全、个人信息保护相关要求，适配电子病历分级评价；医疗 AI 相关功能遵循医疗器械监管相关政策。数据全程在院内网流转，不产生外发，落实医疗数据分级分类管理与去标识化处理。

9.3 文档交付

  • 需求规格说明书
  • 系统部署手册
  • 运维手册
  • 接口文档（含《模型接入标准化规范》）
  • 测试报告
  • 用户操作手册

9.4 培训服务

针对临床、病理、超声、质控、信息科五类角色，分别开展业务操作与系统运维培训，提供培训教材与操作视频，培训后组织考核确认掌握情况。

9.5 质保服务

提供完整免费质保期服务，质保期不低于 3 年，包含缺陷修复、系统调优、版本升级、远程技术支持。质保期内提供响应时限承诺与定期巡检。
