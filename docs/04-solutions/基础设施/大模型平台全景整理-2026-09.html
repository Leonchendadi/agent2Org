多租户 SaaS 需商业授权		 数百种（OpenAI / Claude / Qwen / DeepSeek / 本地模型） 特点：开源 LLM 应用平台领跑者（75k+ Stars、5 万+ 企业用户、C 轮 1.8 亿美元），v1.14 原生支持 MCP、RAG 管线完整，1-3 天上手。

Astron Agent
科大讯飞开源		 开源
Apache 2.0；Docker Compose + Helm 双制品		 OpenAI 兼容接口（实测已接本地 vLLM + Qwen3.8-27B-AWQ-INT4） 特点：企业级 Agentic Workflow 平台（v1.1.2，约 48 万行代码，Java/Python/Go/TS 多语言微服务）：企业→空间→智能体三级多租户模型、可视化工作流编排、OIDC 单点登录（Casdoor）、应用市场、知识库与插件体系。

FastGPT / RAGFlow 开源（均有附加条款） 主流模型 + 本地模型 特点：FastGPT 深耕企业知识库问答（混合检索 + 重排开箱即用）；RAGFlow 主打深度文档解析（表格/扫描件/版面还原）。
场景：知识库 RAG 应用、文档密集型问答。
Astron Agent 实测约束（2026-09 线下部署实测，非官方文档口径）： ① 一个控制台只能服务一个组织——Casdoor 应用与组织一对一绑定，应用迁到新组织后原全局管理员直接失去控制台登录权，名下资产变孤儿；控制台按 OIDC sub 建档，换认证源等于换账号体系；
② 模型按空间隔离——模型必须归属当前空间或用户，跨空间不可复用，多空间需重复配置；创建模型时 API Key 须 RSA 公钥加密后提交；
③ 发布快照机制——编辑态 ≠ 运行态，改完必须显式点「发布」才生效；应用市场"可见 ≠ 可用"，未加入空间的用户能打开、一发消息即返回兜底话术；
④ 模型接入兼容性坑——平台流式解析只识别 reasoning_content，而 vLLM 默认把思考过程放在 reasoning 字段，会导致输出为空，需在推理侧关闭思考模式规避；
⑤ 错误可见性差——平台用"抱歉，我暂时无法回答"兜底话术掩盖真实错误（模型缺失、空间越权等），排障成本极高；
⑥ 实测已通过：OIDC 登录、三级权限与邀请制加人（免短信/邮箱验证码）、可视化编排与发布上架、多轮对话上下文；未验证：知识库/RAG（服务在跑但未接 RAGFlow）、代码沙箱、决策/循环/Agent 节点、RPA 与 MCP 插件、可观测（OTLP/Langfuse 未启用）。
完整证据与 27 条踩坑见项目内 HANDOVER-astron.MD 及交付手册。

Agent 平台选型三条经验（2026 调研共识）： ① 92% 的企业 Agent 项目停在 Demo 阶段，真正商业化率不足 5%——选平台时可观测性、评测与回滚能力比功能数量更重要； ② 单模型 Agent 成本劣势达 4-5 倍，多模型调度已是生存必需； ③ MCP 已成事实标准（十大框架全部支持），A2A 协议原生落地于 Microsoft Agent Framework 与 Google ADK——新项目上平台前先确认 MCP 支持情况。

三、开源 vs 闭源：2026 下半场的五个判断

① 差距约 6 个月且在收窄。开源权重第一梯队（Kimi K3、GLM-5.3、DeepSeek V4）综合指数已压过 GPT-5.6 Sol；闭源旗舰（Claude Fable 5.1、GPT-6 Astra）仍守住最前沿推理与 Agent 上限。
② 开源模型吞吐占比过半。OpenRouter 数据：开源模型处理的词元占比从 1 月 34% 升至 6 月 65%；中国日均词元调用量 175 万亿、全球第一。
③ "开源"多为"开放权重"。真正的 OSI 干净许可：Qwen/Mistral/Gemma 4/MiniMax M3（Apache 2.0）、DeepSeek V4/GLM-Flash/Phi-4（MIT）；Llama 社区许可有 7 亿 MAU 与欧盟限制；GLM-5.3、Kimi K3 为自定义许可——商用前逐个读许可。
④ 分层开源矩阵成型。万亿级 MoE 承接集团业务；10B 级稠密/全模态主攻 PC 与终端；2B～8B 轻量模型主攻端侧与办公自动化——"智能密度"取代参数规模成为竞争标尺。
⑤ 价格战白热化。Qwen3.8-Flash 1 元/百万词元、星火多语言版 1.6 元、混元 Hy4 6 元；国际侧 GLM-5.3-Flash $0.075/M（促销价）已低于 DeepSeek 全时段价格。
