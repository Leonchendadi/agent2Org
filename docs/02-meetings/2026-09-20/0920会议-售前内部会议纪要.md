## 三、逐议题结论

### 1. 宫颈癌"放射影像 AI"需求 —— 假需求，但要现场核实来源

- 招标文件里挂了宫颈癌放射影像 AI 自动识别。**国内所有影像 AI 厂商一致判断：无实用价值、无客户需求**。
- 技术原因（陈焕解释）：肺癌这类靠影像筛出"疑似"，最终确诊靠**病理金标准**；宫颈癌的影像前置环节**根本不存在**，直接走病理（病理图片/锥切），影像 AI 无从下手。
- **不在现场教育客户**（"国内都没有"这种话不要当面说）。改为周二现场**去放射科 / 病理科 / 妇科调研**，搞清楚这个需求是谁提的、从什么角度提的（影像角度还是病理切片角度）。
- 结论：先记录，**不推测，现场问**。

### 2. 造价 / 预算 —— 单一个底座模块就吃掉全部预算

- 陈焕用智能体搜全网招投标/合同数据（关键词：模型平台、模型智能体平台、模型训练平台）做了个造价网页。数据**仅作参考，需逐项核实**。
- 招标参数**第六款"统一技术底座"**——多模型统一接入管理、智能体开发与快速迭代、服务网关与能力封装、数据服务能力、运维监控——**仅这四五十个字**：
  - 按互联网大厂方式交付：**300–800 万**（不含服务器、不含 GPU 算力）
  - 含硬件算力：**过千万，甚至到 2000 万**
- 而项目总预算谢总推测 **400–500 万**（原话："应该不到 500 万"）。
- **11 个模块里的第一个模块，就把预算花完了。**
- 结论：周二现场**必须问清楚**"这句话到底要交付成什么样"，并让平台公司（于新）从上层再探一次预算口径。

### 3. 信创适配 —— 硬约束，且我们没经验

- 政府 / 事业单位**明文规定不得使用英伟达**，只能用**华为鲲鹏 CPU + 昇腾算力卡**。
- 陈焕：只做过英伟达生态，**昇腾没摸过**；华为生态完善度远低于英伟达，**英伟达不用改的东西，华为这边全部要改**。
- 成本预估：**至少上浮 30%–80%**（业界说法）。
- 结论：这条要写进给平台公司/上层的问询（"支持华为鲲鹏/昇腾"），周二现场与院方对接。

### 4. 交付边界与范围 —— 本次会议最核心的决策

**原则**：不按标书逐条验收，一期只做"框架 + 验证式场景"，后期再完善。

**拆分维度**：功能级已不好拆（标书已发出），所以从**数量 / 科室 / 病种 / 诊室 / 点位**层面压缩：

| 模块 | 一期收口边界 |
|---|---|
| 专病 | **只做宫颈癌一个病种**（后续心血管、艾滋病等放二期） |
| 病历生成 | 只做宫颈癌专病病历模板，先做 **10–15 个模板**，但**流程必须闭环**、机制完整；不追求全量五六十个 |
| 病历质控 | 只做宫颈癌相关，做到什么"度"需现场谈定 |
| 超声报告生成 | **只做阴超这一个诊室**（不做心脏 B 超、腹部 B 超、通用 B 超） |
| 随访 | 只做宫颈癌相关患者的专科随访链路 |
| 体检 | 不做整个体检科，只做宫颈癌相关患者的体检摘要与后续跟踪链路 |

- 验收门槛设想：**宫颈癌专病病历模板走通 + 病历生成回写成功**，即可作为半年内验收节点。
- 三条红线（陈小军提）：
  1. **算力/硬件不进我们的预算**（院方已确认不含）
  2. **只做成本可控的内容**，可分期
  3. **每期都要有可见产出物**（发改委项目有定期考核），一期边界必须谈透
- 谢总强调：**这个度的问题必须和院方书面/明确谈定**，否则拿下来也交付不了，对客户、对平台公司都不好。

### 5. HIS / 集成平台接口 —— 最大技术风险点

- 目标系统：**卫宁（转写为"为您/为宁"）集成平台**，粗估需 **约 12 个接口**。
- **取数接口**：相对可控，可能涉及费用。
- **反写接口**：**核心难点**。尤其是**回写电子病历**——涉及草稿回写、认证权限（哪个医生、登录态）等，目前**完全一片迷雾**。
- 卫宁可能以**责任归属**为由拒绝开放回写接口（"写进去出问题谁担责"），也可能**收费**（参照：上次中联要 15 万，最终一分没给）。
- **策略（谢总定调）**：
  - **不主动接触卫宁**，避免被厂商拿捏。
  - 让**医院冲在前面**去协调，接口费我们不出（参照山西东联项目做法）。
  - 我们只在周二**把问题明确抛出来**，明确硬件/接口不达标导致工期拉长的责任归院方。
- **需补充调研**：HIS / LIS / PACS / 超声 / 手术 / 体检 / 随访 / 远程病理 PACS（独立采购）等 **7–8 个子系统**的构成（是否为海泰、卫宁等），以及**现有服务器资源**（可用 vCPU / 内存 / 硬盘）。**资源不足则采购周期 3–6 个月起步，直接拖垮工期。**

### 6. 硬件 —— 医用麦克风/语音采集器

- 招标文件第 7 项第 1 条提到专用医学音频采集器，陈焕理解**应为院方提供**，但**未明确**。
- 谢总：对语音报告类智能体**影响非常大**（用手机 APP 采集会乱），**必须写进问题清单**，现场要求明确由谁提供。

### 7. 自研 vs 外购

| 模块 | 倾向 | 理由 |
|---|---|---|
| 病历质控 | **外购/合作** | 专业厂商才有（上海森亿、汇美、百度等）；中联、卫宁自研的"不好用"；大医院项目常要求不用 HIS 厂商自带质控 |
| 随访 | **自研** | 通用随访市价仅 30–50 万、市场一大把；但医院要的是**专科随访**，厂商做的是通用随访，矛盾点在此 |
| 其他 | 待定 | 谢总定调：**先把需求定死，自研还是外包后面再决策**，不复杂 |

### 8. 方案与资料策略（商业考量优先）

- 现有方案 **5 万字、写得太全**，**不给客户**，自己留着。
- 新做一版 **1–2 页简版**（可由 AI 抽象生成，但思路由人给）。
- 现场策略：
  - **先投屏简版**；简版**可以留给客户**。
  - 讨论时**拿细版对照**，展示技术实力，但**不把细版交出去**。
- 谢总理由：不确定心内科主任/院领导是否已被竞对拿下；**资料一旦流出就流到竞对手里**。这是商业问题，不是技术问题。
- 现有细版方案**不做删减**，后期还用得上。

## 五、周二现场要问的问题清单（初稿）

1. **宫颈癌影像 AI**：这个需求是谁提的？从影像角度还是病理切片角度？放射科/病理科/妇科各自怎么看？
2. **统一技术底座**：招标参数第六款那几句，到底期望交付成什么样？有无可参照的验收标准？
3. **预算口径**：项目实际预算多少？是否按标书逐条验收？能否接受**降级/分期**？
4. **一期边界确认**：只做宫颈癌一个病种、超声只做阴超、病历模板先做 10–15 个闭环——院方是否接受？
5. **信创要求**：是否强制华为鲲鹏 + 昇腾？是否可提供适配环境/测试资源？
6. **接口**：卫宁集成平台是否在维保期？取数/回写接口清单？回写电子病历是否有接口、是否收费？
7. **系统构成**：HIS / LIS / PACS / 超声 / 手术 / 体检 / 随访 / 远程病理 PACS 分别是谁家的？
8. **服务器资源**：现有可用 vCPU / 内存 / 硬盘？能否满足部署？不足由谁采购、周期多久？
9. **硬件**：专用医学音频采集器/麦克风由谁提供？（第 7 项第 1 条）
10. **责任边界**：硬件/接口不达标导致工期延长，责任如何划分？
11. **付款与主体**：签约主体、付款节点、分期验收方式。
